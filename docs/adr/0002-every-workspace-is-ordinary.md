# Every Workspace is ordinary

The sidebar always has at least one Workspace. The first is named Downloads and uses the Mac's Downloads folder. The person can rename it, change its folder, or delete it like any other Workspace. Deleting the last one shows the usual delete dialog, tells them a Downloads Workspace will be created afterward, and then creates that Workspace empty of Downloads.

## Considered options

A permanent undeletable Workspace pinned to the Mac's Downloads folder. Rejected because it would be a second kind of Workspace.
