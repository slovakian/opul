# Workspace symbols come from SF Symbols

A Workspace icon is one emoji or one symbol. The symbols come from SF Symbols, in a short sidebar set, because those icons match the Mac and ship with the system. Emoji is how a person marks a Workspace as their own.

## Considered options

Lucide, which is free to ship under ISC and MIT if the license text stays with the app. Rejected because those stroke icons would look like a different app in the sidebar.
